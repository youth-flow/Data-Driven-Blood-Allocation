# 02｜AXID-v4：患者局部病例组合 × 日级情境匹配的合成需求 DGP

> **版本**：AXID-v4 / `axid_v4_local_case_mix`；**状态**：独立于已完成 AXID-v3 正式实验的下一版机制候选。先做不训练预测器的 Oracle 校准，再冻结正式运行版本。  
> **生成器参考代码**：`AXID_v4_reference.py`（随本协议一同提供）；**性能合同**：`04_AXID_v4_Performance_Protocol.md`。  
> **不改变**：DAT 模块拓扑、P1/P2/P3 三个研究问题、τ=0.9、五个 G、10 个独立重复、每重复 2,500 训练日 + 3,000 测试日、随机方法 3 Seed、禁止根据正式测试结果调参。  
> **主指标**：**Prescriptiveness**；辅助指标为日均成本 **MeanCost** 和期末达到目标库存的比率 **SL_G**。  
> **科学定位**：v4 针对 v3 的“局部患者作用过早被压缩成全局标量”的观察结果构造更有机制辨识度的合成环境，不使用 DAT 或其他神经网络作为 teacher。**v3 数据及结果保留，v4 使用全新的正式测试数据。**

## 0. 设计目标：同时识别三个而非一个效果

| 实验 | 研究问题 | v4 的生成机制对应 |
|---|---|---|
| P1 | 完整事前患者信息能够创造多大运营价值，DAT 实现多少？ | 日级情境、逐患者风险及病例组合共同驱动需求分位数，保留 SAA–Oracle 的非微小差距 |
| P2 | Self-Attention / Cross-Attention 在有限训练样本下分别能否增加收益？ | **先**由同日患者邻近关系更新每个患者的需求风险，**再**由日级情境决定相关患者的聚合权重 |
| P3 | 血液中心从无订单信息、订单汇总、临床汇总到完整患者共享，获得多少额外收益？ | 聚合信息可识别风险比例，却不能恢复个体风险—申请—术式—邻近病例关系 |

> **重要界限**：DGP 可以设计为具有上述两类非线性关系，但无法数学保证 Self-Attention 优于 No-SA、DeepQR 或 DeepSets（后者也可以逼近连续置换不变函数）。正式排名必须由独立数据判定。**本版本是 v3 结果引发的新研究设计，不把它伪装成 v3 的事前固定假说。**

## 1. 记号、维度和生成顺序

一日为一个独立样本：

\[
Z=(A,X),\qquad A=\{a_i\}_{i=1}^{N},\qquad a_i=(u_i,v_i,r_i,s_i)\in[0,1]^4.
\]

`A` 是无序患者集合；`X∈[0,1]^9` 是日级输入。所有日期的外生变量相互独立；同一日的需求分量共享未观测冲击 `U`。基本设置：

| 符号 | 固定数值 | 业务含义 |
|---|---:|---|
| `M` | 8 | 每日决策前可见患者数上界 |
| `K_new` | 12 | 决策后新增订单机会数上界 |
| `B` | 60.5 | 当日需求的已知硬上界 `3(M+K_new)+0.5` |
| `τ` | 0.9 | 短缺成本权重、目标条件分位数水平 |
| `𝒢` | `{260,280,300,320,340}` | 期末目标库存网格；主展示 `G=300` |
| `σ(x)` | `1/(1+exp(-x))` | Logistic 映射 |

## 2. 阶段 A：事前信息 `A,X,I` 的生成

### A1. 外生运营状态与库存

\[
 c_1,c_2\overset{\rm iid}{\sim}U(-1,1),\quad
 \varepsilon_I\sim U(-70,70),\quad
 \boxed{I=315+20c_1+\varepsilon_I\in[225,405].}
\]

- `c1`：血液中心在决策前可获取的计划业务压力代理；`c2`：可获取的区域应急压力代理。
- `I`：期初可用库存，允许随 `c1` 改变；**G 不参与 `I` 或 `D` 的生成**，库存不跨日滚动。
- 实证移植时应核查 `c1,c2` 是否真的属于血液中心可提前获得的外生信息；如果只能由医院提供，则 L0 的权限需要另行重定义。此处属于 Synthetic 可见性假设。

### A2. 可见患者数量和四维特征

\[
\boxed{N=3+\operatorname{Binom}\!\left(5,\sigma(0.25+0.45c_1)\right),\qquad 3\le N\le8.}
\]

对 `i=1,…,N` 独立抽样：

\[
\begin{gathered}
 u_i,v_i\overset{\rm iid}{\sim}U(0.05,0.95),\quad
 R_i,s_i\overset{\rm ind}{\sim}\operatorname{Bernoulli}(0.5),\\
 \boxed{r_i=0.15+0.70R_i,\qquad z_i=2R_i-1\in\{-1,1\}.}
\end{gathered}
\]

- `u_i`：标准化申请量；`v_i`：标准化备血量；`r_i`：决策前临床风险档位（低风险 0.15／高风险 0.85）；`s_i`：术式／业务类型（二元）。
- `R_i,z_i` 是 **DGP 内部的风险重编码**，模型只收到原始 `r_i`；`R_i` 与 `(u_i,v_i,s_i)` 独立是用于识别“风险分配到哪份订单”的受控合成设定，不是对真实医院的经验假设。
- `Y_i`、`U`、未来新增订单及任何内部机制统计量不能作为事前预测模型输入。

### A3. 日级输入向量（9 维）

\[
\boxed{
 X=\left(
 \frac{c_1+1}{2},\frac{c_2+1}{2},\frac{I-225}{180},
 \frac N8,\frac{\sum_i u_i}{8},\frac{\sum_i v_i}{8},
 \bar r,\overline{r^2},\bar s
 \right)\in[0,1]^9.
}
\]

其中 `\bar r=N^{-1}\sum_i r_i`，`\overline{r²}=N^{-1}\sum_i r_i²`，`\bar s=N^{-1}\sum_i s_i`；向量已经包含 `N/8`，**模型不得再内部追加人数坐标**。为了与 v3 共用输入接口，保留 `\overline{r²}`；因风险仅有两档，它满足 `\overline{r²}=\bar r-0.1275`，不代表一条独立的信息来源。

## 3. 阶段 B：从患者邻近关系到状态条件化的真实需求机制

### B1. 局部患者相似度：包含资源特征及术式

对 `j≠i`，定义：

\[
\boxed{
 k_{ij}=\exp\!\left[
 -\frac{(u_i-u_j)^2+(v_i-v_j)^2}{2h_A^2}
 -\eta_s(s_i-s_j)^2
 \right],\quad h_A=0.22,\ \eta_s=1.5.
}
\]

`k_ij` 是患者 `i,j` 的资源需求/术式相似度。核严格为正且 `N≥3`；**不使用患者顺序与自环**。高斯核与术式惩罚为光滑、业务可解释的局部相似机制。

### B2. **患者级局部高风险聚集效应**（v4 的关键改动）

\[
\begin{aligned}
 p_i^{\mathrm{loc}}&=\frac{\sum_{j\ne i}k_{ij}R_j}{\sum_{j\ne i}k_{ij}},
 &p_i^{\mathrm{other}}&=\frac{\sum_{j\ne i}R_j}{N-1},\\
 \boxed{T_i&=R_i\tanh\!\left[2\big(p_i^{\mathrm{loc}}-p_i^{\mathrm{other}}\big)\right].}
\end{aligned}
\]

- `p_i^loc`：与患者 `i` 申请/备血/术式相近的其他患者中，高风险患者的加权比例；`p_i^other`：排除自身后全体其他患者的高风险比例。
- `T_i`：**高风险患者所在局部群体的超额高风险集中程度**，取值在 `[-1,1]`；低风险患者的该项为 0。正值表示在与自身相近的病例群体中，高风险更聚集；负值表示局部高风险占比低于全日其他患者平均。
- `tanh` 是平滑的阈值/饱和响应，避免简单线性关系无限扩大。**这一项将直接改变患者 `i` 自己的需求概率，而不是先压成日级标量再加到所有患者上。**
- 这里的“患者交互”解释为**同日病例组合/资源调度压力对实际用血转化的条件关联**，**不是**宣称其他患者的病情直接引起某个患者的生理用血需求。

### B3. 日级情境对患者的重要性选择（Cross-Attention 的统计对象）

\[
\begin{aligned}
 m_u(c_1)&=0.5+0.3c_1,\quad m_v(c_2)=0.5+0.3c_2,\\
 b_i^{\mathrm{match}}&=-\frac{(u_i-m_u)^2+(v_i-m_v)^2}{2(0.23)^2}+0.5(2s_i-1)c_2,\\
 \boxed{\omega_i(A,X)&=\frac{\exp(b_i^{\mathrm{match}})}{\sum_j\exp(b_j^{\mathrm{match}})}},\qquad \sum_i\omega_i=1.
\end{aligned}
\]

`m_u,m_v`：由当天计划/应急压力决定的匹配中心；`b_i^match`：患者与当天病例组合的匹配分数；`ω_i`：当天对不同患者群体的条件化重视程度。它是生成过程的真实统计权重，**不是**把注意力权重作为额外输入，也不是 DAT 的参数。

### B4. 全局情境信号与经情境选择的局部信号

\[
\begin{aligned}
 H_{\mathrm{align}}&=\sum_i\omega_i z_i,&
 H_{\mathrm{shape}}&=\sum_i\omega_i(2u_i-1)(2s_i-1),\\
 \boxed{H_{\mathrm{ctx}}&=0.55H_{\mathrm{align}}+0.20H_{\mathrm{shape}}},&
 \boxed{H_{\mathrm{local}}&=\sum_i\omega_i T_i}.
\end{aligned}
\]

- `H_ctx∈[-0.75,0.75]`：日级情境选中的风险及资源—术式组合，承接 v3 已验证的 **Cross-Attention 型全局信号**。
- `H_local∈[-1,1]`：当天更应被关注的患者群体中，局部高风险病例聚集的程度，承接 **Self-Attention 后再用 Cross-Attention 聚合**的两步依赖。
- 相比 v3，**取消原先单一的 `0.25 H_peer` 全局交互修正**，把交互作用改成下述患者级 `T_i`，并通过 `H_local` 影响决策后新增订单，避免仅放大全局统计量。
- `T_i,H_ctx,H_local,k_ij,ω_i` **全部只在 DGP 内部计算**，不能作为模型输入，也不能拿它们为某一基线量身定制特征。

## 4. 阶段 C：真实患者用血、未来新增订单与总需求

### C1. 单个已知患者实际用血

抽取全日共享的潜在需求冲击：

\[
 U\sim\mathcal N(0,1),\qquad \rho=0.45.
\]

定义患者 `i` 的发生 Logit 和用血数量参数：

\[
\boxed{\begin{aligned}
 \ell_i={}&-1+0.6u_i+0.4v_i+0.6z_i+0.4s_i
 +3H_{\mathrm{ctx}}+0.3c_1+0.2c_2
 +\underbrace{2.2T_i}_{\text{患者自身的局部作用}},\\
 \pi_i={}&\sigma(-0.4+0.5u_i+0.3v_i+H_{\mathrm{ctx}}+0.9T_i).
\end{aligned}}
\]

给定 `A,X,U` 后，患者间需求分量条件独立：

\[
\boxed{\begin{aligned}
 B_i&\sim\operatorname{Bernoulli}\!\left(\sigma(\ell_i+0.45U)\right),\\
 V_i&=\tfrac12[1+\operatorname{Binomial}(5,\pi_i)],\\
 Y_i&=B_iV_i\in\{0,0.5,1,1.5,2,2.5,3\}.
\end{aligned}}
\]

`B_i`：是否实际用血；`V_i`：一旦用血的数量；`Y_i`：患者实际用血。局部效应直接进入 `ℓ_i` 与 `π_i`，因此同样的患者自身特征，在不同同日病例组合中可有不同的真实需求分布。**`Y_i` 仅能作为 Flat-ETO 训练期的额外结果标签。**

### C2. 决策后新增订单（12 个潜在机会）

\[
\boxed{\begin{aligned}
 p_{\mathrm{new}}(Z,U)&=\sigma\!\left(-0.7+3.5H_{\mathrm{ctx}}+0.5\bar z
 +0.5c_1+0.2c_2+\underbrace{3.0H_{\mathrm{local}}}_{\text{病例组合压力}}+0.45U\right),\\
 \pi_{\mathrm{new}}(Z,U)&=\sigma(-0.1+1.2H_{\mathrm{ctx}}+0.3c_2+0.15U),\\
 L&\sim\operatorname{Binomial}(12,p_{\mathrm{new}}),\\
 D_{\mathrm{new},0}&=\tfrac12\left[L+\operatorname{Binomial}(5L,\pi_{\mathrm{new}})\right].
\end{aligned}}
\]

`L`：决策后实现的新增订单数；`p_new`：每个潜在订单出现的概率；`π_new`：新增订单的需求量参数；`D_new,0`：新增订单需求（无连续扰动）。`L` 与 `U` 都是事后或潜在变量，禁止向预测器开放。

### C3. 当日总需求与支持上界

\[
\boxed{
 J\sim U(0,0.5),\quad J\perp(A,X,U,Y,L),\qquad
 D=\sum_{i=1}^{N}Y_i+D_{\mathrm{new},0}+J\in[0,60.5].
}
\]

`J` 是独立连续余量，令 `D` 的条件分布在半单位区间上为分段均匀密度，使条件分位数可连续反演。生成及计算不得对 `D` 或预测分位数进行半单位取整。

## 5. Full-information Bayes Oracle：真条件分布而非未来先知

令 `D0=D-J`，`p_k(Z)=Pr(D0=0.5k | Z)`。给定 `Z,U=u`，每个患者七类需求 PMF 为：

\[
\begin{aligned}
 \Pr(Y_i=0\mid Z,u)&=1-b_i(u),\qquad b_i(u)=\sigma(\ell_i+0.45u),\\
 \Pr(Y_i=0.5j\mid Z,u)&=b_i(u){5\choose j-1}\pi_i^{j-1}(1-\pi_i)^{6-j},\quad j=1,\ldots,6.
\end{aligned}
\]

每个**潜在新增订单**也有同结构七类 PMF，发生概率 `p_new(Z,u)`，数量参数 `π_new(Z,u)`。先在**同一个固定 `u`** 下卷积 `N+12` 个 PMF，再对共同冲击积分：

\[
\boxed{
 p_k(Z)=\int_{\mathbb R}\left[
  \left(\underset{i=1}{\overset N\ast}p_{Y_i\mid Z,u}\right)
  *\left(p_{{\rm pot,new}\mid Z,u}^{\ast12}\right)
 \right]_k\varphi(u)\,\mathrm du,
\quad k=0,\ldots,6(N+12).
}
\]

**禁止**分别积分每个患者的边际需求 PMF 后再卷积：那会错误地删除共同冲击 `U` 的相关性。使用固定 25 节点 Gauss–Hermite 数值积分，并在独立少量输入上做 16/25/32 节点检查。

记 `C_k=Σ_{j≤k}p_j(Z)`、`C_{-1}=0`，最小 `k` 满足 `C_k≥τ`，则：

\[
\boxed{Q_\tau^\star(Z)=\frac{k}{2}+\frac12\frac{\tau-C_{k-1}}{p_k(Z)},\qquad\tau=0.9.}
\]

对于任意预测 `y`，可用以下解析积分计算真实条件 Pinball 成本（可供**DGP 预检查**）：

\[
\begin{aligned}
 \phi_Z(y)=\sum_k p_k(Z)\big\{&\tau\big([0.5k+0.5-y]_+^2-[0.5k-y]_+^2\big)\\
 &+(1-\tau)\big([y-0.5k]_+^2-[y-0.5k-0.5]_+^2\big)\big\}.
\end{aligned}
\]

正式测试的 Oracle 决策只能读取事前 `A,X,I`，但评价成本时使用与所有模型相同的**当天真实实现需求 `D`**，不得把条件期望 Oracle 成本与模型实现成本混为一套配对主结果。

## 6. 决策与三项评价：**Prescriptiveness 为唯一主指标**

对于任意模型 `f(Z)`，设 `q` 为补货量、`I_end` 为期末库存：

\[
 q_{f,G}=[f(Z)+G-I]_+,\qquad I_{\mathrm{end}}=I+q_{f,G}-D.
\]

设 `τ=0.9`，单日成本与目标服务率为：

\[
 c_{f,G}=\tau[G-I_{\mathrm{end}}]_++(1-\tau)[I_{\mathrm{end}}-G]_+,
 \quad C_G(f)=\mathbb E[c_{f,G}],
 \quad SL_G(f)=\Pr(I_{\mathrm{end}}\ge G).
\]

主评价指标：

\[
\boxed{
 \mathcal P_G(f)=\frac{C_G(\mathrm{SAA})-C_G(f)}
 {C_G(\mathrm{SAA})-C_G(\mathrm{Oracle})}.
}
\]

五个 `G` 的联合 P 必须**先汇总成本差，再取比值**：

\[
\boxed{
 \mathcal P_{5G}(f)=
 \frac{\sum_{G\in\mathcal G}\{C_G(\mathrm{SAA})-C_G(f)\}}
 {\sum_{G\in\mathcal G}\{C_G(\mathrm{SAA})-C_G(\mathrm{Oracle})\}}.
}
\]

- **主指标** `PrescriptiveP` 越高表示实现的 SAA→完整信息 Oracle 潜在成本节约比例越高，理论总体下 Oracle=1、SAA=0；有限测试估计可小于 0 或大于 1，**不得裁剪**。
- **辅助指标** `MeanCost=C_G(f)` 越低越好，是 P 的成本基础；`SL_G` 是期末库存达到目标 `G` 的频率，**不是无成本约束下越高越好**，过量备血可能提高 SL 但增加超目标库存持有成本。
- Oracle 是条件于当前完整 `A,X` 的 Bayes Oracle，**不是**观测真实未来 `D,U` 的 perfect-hindsight Oracle。

## 7. P3 四种信息共享情境（删除 L3，保留原等级编号）

| 等级 | 血液中心事前可见信息 | 真实患者 Token / Mask | 制度解释 |
|---|---|---|---|
| **L0** | `c1,c2,I` | 固定 Dummy Token，不暴露真实 N | 无医院患者订单信息，仅已知外生环境与库存 |
| **L1** | L0 + `N/8, Σu/8, Σv/8` | 同 L0 | 医院提供基础订单数量与资源需求汇总 |
| **L2** | L1 + `mean(r),mean(r²),mean(s)` | 同 L0 | 医院进一步提供风险／术式病例组合统计 |
| **L4** | 完整 `X[9]` + 完整 `A[N,4]` | 真实患者 Token 及 Mask | 医院—血液中心共享信息系统提供逐患者申请、备血、风险和术式 |

`L0⊂L1⊂L2⊂L4` 指可用信息集合的包含。L0–L2 全部使用**恒定 Dummy Token + 固定有效 Mask**，防止通过 `N`、序列长度或 Padding 泄露未授权信息。日级未授权坐标填**固定常数**；L4 用完整真实患者集合。跨等级固定 DAT 拓扑和已分配的参数预算，各等级从头训练，不复用 L4 权重。

风险分配敏感性来自 `H_align` 与新的 `T_i`：即使保持 `N,Σu,Σv,mean(r),mean(s)` 不变，对不同患者交换高/低风险标签仍可改变 Full Oracle 分位数。**但训练后 L2–L4 的 P 差不等于精确的 Bayes 信息价值差；后者需要各等级专属 Oracle。**

## 8. 机制／Oracle 预检查：实际计算结果（尚无 v4 模型训练结果）

> **本节均为生成器侧的 Monte Carlo 预检查，不是 P1/P2/P3 模型成绩，不能推导“Full 必定战胜 No-SA”。**

- 校准输入池：**4,500** 个独立 `Z`，25 节点 GH，平均真实条件 PMF 估计总体无条件分布，得到 `SAA_pop` 分位数约 **29.7809**。
- 评价输入池：另外 **4,500** 个独立 `Z`，25 节点 GH，在**真实条件期望成本**下评价 SAA_pop 与 Full Oracle；固定校准/评价种子 `2026110801`、`2026110802`。
- 局部机制反事实：在同一 `Z` 上把 `T_i=H_local=0` 的分位数当作替代预测，**仍按真实 v4 条件分布评价**它的成本。该替代预测不是“无 Self-Attention 的 Bayes Oracle”，也不是严格的信息价值分解。

| 260 | 5.0473 | 4.6718 | 7.44% | 0.0422 |

## 9. 必须通过的生成器验收与理论接口

1. `A[N,4]`、`X[9]`、`3≤N≤8`、`0≤D≤B=60.5`；`X` 每坐标都在 `[0,1]`。
2. 全部患者特征及机制均置换不变；`T_i` 随患者一起置换，但 `H_ctx,H_local` 与条件总需求 PMF 不变。
3. `k_ij>0`、`j≠i`、局部核归一化；同一患者的 `R_i` 不可被当成邻居。
4. 每个条件 PMF 非负且总和为 1；反演分位数后的连续 CDF 接近 τ，Gauss–Hermite 16/25/32 进行小样本核验。
5. 先对固定 `U` 条件联合卷积，再积分 `U`；不允许忽略患者和新增订单的共同冲击相关性。
6. 数据集的训练、测试及机制校准随机种子完全分离，旧 AXID-v3 结果不覆盖、不合并。
7. 若拓展到原 T1–T3 理论实验，应更新其维度记号；性能版本仍可设 `M=8,d_a=4,X∈R^9,d_x=8,d_m=min(C(12,8)-1,2M d_a+1)=65,d_eff=73,d_model=80≥74`。固定 `N` 切片上的机制平滑且对患者置换不变，具体理论近似常数需根据新机制另行评估。
8. `Y_i` 仅 Flat-ETO **训练**可见，潜在 `U`、`H_ctx`、`T_i`、`H_local`、真实条件 PMF、Full Oracle 分位数不得给任何预测器作为输入或标签。
9. `AXID_v4_reference.py` 作为生成和 Oracle 的数值参考，正式工程要对随机数抽样、字节级字段语义及公式做一致性测试；本文件中的 Pilot 不表示已经完成正式训练。

**版本说明**：AXID-v4 是基于已公开的 v3 消融结果提出的新合成场景。其严谨作用是对“患者级局部关系是否创造可利用的额外决策信号”进行独立新实验，而不是重新定义已完成 AXID-v3 的结果。
