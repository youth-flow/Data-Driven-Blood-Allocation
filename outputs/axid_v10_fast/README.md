# AXID-DC v10 formal performance results

This directory is the complete lightweight result package for the frozen
AXID-DC-v10 performance run. It contains all reportable metrics and the
day-level objects needed to audit them, while excluding regenerable synthetic
input matrices and fitted model binaries.

## Run identity

- DGP: empirically calibrated AXID-DC v10 MDCEV
- Data identity: ce83de8cb9baa8a5545b1ff5b9093f5cb3cd11ee446f6d41c11522e27d5aa13b
- Train/test days: 524,288 / 10,000
- Quantile and common target: tau = 0.9, G = 256
- Model seed: 2026111404
- DGP train/test seeds: 2026111401 / 2026111402
- Bootstrap: 2,000 paired test-day resamples
- Conditional Oracle: 4,096 paths per test day; 500-day audit at 16,384 paths

## Included

- final_metrics.csv: all 17 P1/P2/P3 configurations
- bootstrap_intervals.csv: paired 95% percentile intervals
- daily_metric_arrays.npz and daily_metric_names.json: day-level metric inputs
  for exact re-aggregation
- jobs/**: every method's prediction, fit summary, result, frozen signature,
  and completion manifest
- oracle/**: conditional-Oracle predictions, block quantiles, stability audit,
  and manifest
- stages/**: stage completion and timing records
- dataset/*.json and dataset/generation.yaml: schema, seeds, hashes, and
  preprocessing metadata

## Deliberately excluded

The following files are not experiment results and are regenerated by the
frozen code and seeds, so they are not stored in Git:

- dataset/patients.npy
- dataset/patient_labels.npy
- dataset/patient_offsets.npy
- dataset/daily.npz
- jobs/**/artifact.pt

Those inputs and model binaries total about 546 MiB; two arrays exceed
GitHub's ordinary 100 MiB per-file limit. Their identities remain recorded in
the committed manifests. No real patient-level or processed clinical data is
included anywhere in this result package.

## Reproduction

Run from the repository root in the attention environment:

~~~powershell
python scripts/run_v10_experiment.py --stage data
python scripts/run_v10_experiment.py --stage p3
python scripts/run_v10_experiment.py --stage p2
python scripts/run_v10_experiment.py --stage p1 --approve-p1
python scripts/run_v10_experiment.py --stage metrics --oracle-workers 6
~~~
