# 合成 DGP 与六组实验协议

本协议于 2026-11-02 固定研究设计。机器可读版本为 `synthetic/configs/confirmed_protocol.yaml`。
这是新生成器 v3 的设计合同，不是已经完成正式训练的声明。现有 `reference.yaml`、
`study.yaml` 和 A/B/C 入口仍为 v2；不能把旧入口的输出标成执行了本协议。
不读取真实原表或派生数据，不向生成器提供真实模型权重。运营模型及理论正文不改。

## 1. 一套生成机制，两个规模

日样本独立同分布；日期只作唯一标识，不输入逐日确定变化的日历。
默认使用连续需求版，支持已知条件分布的 oracle；原半单位离散版作为单列的稳健性实验。
理论规模与性能规模来自同一机制。每条样本量/容量曲线内，规模、分布及系数固定。

| 设置 | 理论校准 | 性能主实验 |
| --- | ---: | ---: |
| 可见订单上界 M | 2 | 8 |
| 订单坐标维数 d_a | 3 | 3 |
| 除人数坐标外的日级维数 d_x（含库存） | 7 | 7 |
| 新增订单上界 K | 4 | 4 |
| 需求上界 B | 18.5 | 36.5 |
| DAT 潜维 | 36 | 128 |

规模是可复现实验设定，不是医院真实规模的估计。压缩维数是为了明确理论维度和
信息集合，不把科室、类型等冗余人工类别堆入主 DGP。以后增加高维场景需单列协议。

## 2. AXID 的完整生成顺序

记 s(x)=1/(1+exp(-x))，所有不同日的外生随机变量独立。

### 2.1 已知日级情境与期初库存

独立生成 c_1,c_2 ~ Uniform(-1,1)，分别代表计划业务强度和急诊压力。
再生成 e_I ~ Uniform(-70,70)，并令

    I = 315 + 20 c_1 + e_I，I ∈ [225,405]。

I 不随评价 target 改变。不滚动库存，不把历史策略的到货量当作模型输入或标签。
在这个 DGP 中，给定 c_1,c_2 后，库存噪声不提供额外需求信息；
不预设“加入库存一定改善分位预测”，但 I 始终参与配送决策。

### 2.2 可见订单集合 A

    N = 1 + Binomial(M-1, s(-0.2+0.4 c_1))。

故 1≤N≤M。对每个订单独立生成

    r_i ~ Beta(2,3)，
    u_i = Binomial(12, 0.25+0.25 r_i) / 12，
    v_i = Binomial(16, 0.15+0.20 r_i) / 16。

模型直接接收 a_i=(u_i,v_i,r_i)∈[0,1]^3。
物理申请量为 6u_i，备血量为 8v_i，r_i 是已知临床风险分数。
二者无大小约束，不声称备血量一定大于申请量；r_i 不是事后实际用血结果。
集合顺序没有业务含义。数值实现不得用排序位置生成需求。

### 2.3 日级输入 X（8 个坐标）

    X = ((c_1+1)/2, (c_2+1)/2, (I-225)/180, N/M,
         sum(u_i)/M, sum(v_i)/M, mean(r_i), mean(r_i^2))。

所有坐标均在 [0,1] 内，I=225+180 X_3。
理论中的 X~ 不含人数坐标，因此 d_x=7，而不是 8。
这些汇总来自同一份可见 A，不使用 D 或未来订单；N/M 是显式输入。
用预先已知支持作固定变换，不用训练样本均值/方差重新定义函数类。
实现时 I 可单独存储以计算 q，但进入网络只出现一次。

### 2.4 可见订单的当日需求

以申请量相似度构造平滑的同群风险：N=1 时 peer_i=0；否则

    w_ij = exp(-(u_i-u_j)^2/(2*0.25^2)), j≠i，
    peer_i = sum_{j≠i} w_ij r_j / sum_{j≠i} w_ij。

再定义

    l_i = -2 + 0.35 log(1+6u_i) + 0.15 log(1+8v_i) + 1.2 r_i
          + alpha (0.8 c_1 u_i + 0.6 c_2 r_i) + gamma r_i peer_i，
    pi_i = s(-0.5 + 0.3 log(1+6u_i) + 0.15 log(1+8v_i) + 0.7 r_i)。

生成未来共同冲击 U~Normal(0,1)。给定 A,X,U 后，独立抽取

    B_i ~ Bernoulli(s(l_i+rho U))，
    V_i = 0.5(1+Binomial(5,pi_i))，Y_i=B_i V_i。

这是明确的概率机制，不使用 DAT 或其他预测器当 teacher。
相似订单相互作用是假设的统计机制，不声称识别了临床因果关系。

### 2.5 当天新增需求与总需求 D

    L ~ Binomial(4, s(-0.7+0.4 c_2+0.3 c_1+rho U))，
    pi_new = s(-0.4+0.5 c_2+0.2 rho U)，
    D_new,0 = 0.5(L+Binomial(5L,pi_new))，
    J ~ Uniform(0,0.5)，D_new=D_new,0+J，
    D = sum_i Y_i + D_new。

J 为独立的连续小额需求余量；D 的单位允许连续。离散稳健性版本单独置 J=0。
不把连续 D 事后四舍五入。支持为 [0,3(M+4)+0.5]，不裁掉高需求标签。
U、J、L、Y_i、D_new 的实际值不进入预测输入。
订单结果 Y_i 仅提供给声明需要订单监督的 Flat-ETO；DAT/DeepQR 只用日级 D。

### 2.6 四个机制场景

| 场景 | alpha | gamma | rho | 用途 |
| --- | ---: | ---: | ---: | --- |
| S1 | 0 | 0 | 0 | 给定输入后订单独立的参照 |
| S2 | 1 | 0 | 0 | 加入订单与已知日级情境的交互 |
| S3 | 1 | 1.5 | 0 | 再加入订单构成作用 |
| S4 | 1 | 1.5 | 0.8 | 再加入未观测共同冲击 |

相同数据重复中各场景共享 A,X,I，需求机制改变。场景差异同时可能改变均值和方差，
不能将跨场景所有胜负变化都解释为注意力模块的单一因果效果。

## 3. 理论兼容性与 oracle

固定 N=n 后，D_0=sum(Y_i)+D_new,0 在 0,0.5,...,3(n+4) 各网格点均有正概率。
紧输入、有限 n、平滑且严格正的条件概率使其各概率关于输入连续，且有统一正下界。
同群核分母在 n>1 时有正下界；共同冲击积分保留有界导数。
加宽度恰为网格间距的 J 后，条件 CDF 连续、严格递增；所得分位函数在各人数切片上
置换不变且 Lipschitz，因而满足 alpha_Holder=1。存在性不表示其常数数值很小。
需求密度至多 2，也满足理论中可选二次风险上界的充分条件。
采用连续版是一个充分构造；理论本身并没有要求所有需求必须连续。

令 p_k=P(D_0=0.5k|A,X)，C_k=sum_{j≤k}p_j，C_{-1}=0。
找到 C_{k-1}<tau≤C_k，则

    Q_tau = 0.5 k + 0.5 (tau-C_{k-1})/p_k。

S1–S3 用有限离散 PMF 卷积；S4 给定 U 后卷积，再做一维正态积分。
条件风险可对每个均匀区间解析积分；对 Z 的总体平均仍用独立输入样本近似。
S4 报告尾部截断、积分精度及数值稳定性，不能把有限节点积分标成无误差 oracle。
函数拟合标签使用同一个完整信息 oracle，不使用当天实际实现值。
低信息等级的专属 Bayes oracle 须积分掉被隐藏的信息，不能直接把完整信息 oracle 当作它。

## 4. DAT 与理论的对应

共享两层 ReLU 订单 MLP → 一个 pre-LN self-attention+FFN 残差块；
8维 X 的仿射日级编码 → 一个 pre-LN cross-attention+FFN 残差块；
最终 LN → 标量仿射读出 → clip[0,B]。无位置编码，4头，LN epsilon=1e-5。
训练和评价 dropout 均为0，原始 pinball 损失，weight decay=0。
每个 tau 独立训练同一结构，不共享不同 tau 的权重；主结果不做跨分位排序后处理。
不预训练、不使用 LoRA、不冻结部分结构；函数逼近诊断的权重也不转入主实验。

理论尺寸按 d_m=min{choose(d_a+M,M)-1,2Md_a+1}，d_eff=d_m+d_x 检查：

| 设置 | d_m | d_eff | 要求 d_model≥ | 采用 d_model |
| --- | ---: | ---: | ---: | ---: |
| 理论 M=2 | 9 | 16 | 34 | 36 |
| 性能 M=8 | 49 | 56 | 114 | 128 |

理论基准订单 MLP 隐藏宽32、患者 FFN72、日级 FFN32；性能分别128、256、256。
基准闭欧氏参数球半径 R=100；每步投影。其他矩阵/偏置/LN 的附加上界设为同一个 R，
从而不再用固定算子上界4或固定LN上界2截掉增长筛类。监测投影后的实际全局范数。

逼近/联合增长时固定潜维36、块数、头数及患者 FFN72，只增长订单 MLP 和日级 FFN的
共同隐藏宽 H，所有稠密参数位置均计数。令 p_0 为 H=32 的参数数目，
R_p=100(p/p_0)^2，构成预先确定的紧参数类。这个多项式包络在充分大预算下可以
容纳定理构造所需的多项式半径；未把有限档位已经进入渐近区当成已证事实。
实现前后用 `synthetic/scripts/check_protocol.py` 核对参数量和维度。

已用当前真实DAT模块构造核验：理论基准20,429个参数，性能基准283,777个参数。
理论宽H时p(H)=16,813+113H；H=16/32/64/128/256/512分别对应
18,621/20,429/24,045/31,277/45,741/74,669个参数。
实际构造通过标量输出范围、订单置换不变性和参数投影检查。
这是模块/协议核验，不是新生成器或六组训练已完成的证据。

## 5. 理论三组实验

统一 tau=0.9。T=500/1000/2000/4000/8000/16000；需要更大尺度时预先登记的扩展为
32000/64000/128000。正式200份独立训练数据；先做20份接口/耗时试运行，试运行不作为
另外新增的选择样本。固定三个初始化，按原训练 pinball 选最小者；报告这个算法规则。
不按测试结果选初始化，不把三个初始化计成三份独立训练数据。
评价初始使用50000个独立输入，计算条件期望风险并报告总体积分的Monte Carlo误差。
理论轨道不把500日验证集并入训练，横轴T就是实际参与拟合的日数。
数值DAT训练预设AdamW、学习率0.0003、batch128、300轮、weight decay=0、梯度裁剪1；
按原始完整训练pinball保留checkpoint，不按oracle或测试标签早停。
这是一项固定数值训练规则，未获得全局最优证书就不标为精确ERM。

### T1 估计误差

固定 H=32、类及R=100，重复抽训练集。S2/S3报告相对 Bayes 的总超额风险分布；
一般情况下不知道 f_p^dagger，不能把它直接改名为精确估计误差。
增设可实现校准：固定 N=M，订单发生概率、数量概率和新增需求概率全部固定为常数，
关闭情境/同群/共同冲击项。条件需求分布独立于 A,X，真实分位数为可精确表示的常数，
故该场景 App=0。常数参数预设为 p_issue=0.35,p_quantity=0.4,p_new=0.3,p_new_quantity=0.4。
先在只训练输出偏置的DAT常数子类上使用样本分位数求精确ERM；再运行完整DAT数值训练。
前者是可解校准，不宣称它验证了整个神经函数类；后者不能未经认证称为精确ERM。
画中位数、90%/95%分位数和重复抽样分布。只有合法显式常数算出后才报告界的越界率。
界若退化为平凡有界性上界，照实报告；不能拟合一个包络常数冒充理论常数。

### T2 逼近能力

S2/S3/S4，H=16/32/64/128/256/512，R随p增长。
直接用新生成的输入和真实条件分位数做无噪声函数拟合，平方误差作为诊断拟合目标。
固定独立诊断/评价输入，训练预算在每个容量增加一倍后检查平台；记录预算与收敛轨迹。
报告 oracle L1/L2、测试点最大误差、所训练函数的可达到超额 pinball 风险。
这些是可达到误差，对真正类内逼近误差提供上界证据；测试点最大值不是全域sup误差。
这是单独诊断，不是主训练的预训练阶段，不给性能比较中的任何模型转移权重。

### T3 联合一致性

S2/S3内固定DGP，采用 H(T)=max(1,floor(32 sqrt(T/2000)))，R_p按上式增长。
实际p(T)=固定参数开销+O(H(T))，因此p(T)=O(sqrt(T))，p(T)log p(T)/T→0。
两个隐藏层均无界增长且范数包络增长，可对照逼近条件与一致性充分条件。
另外比较 H=32、H=128 的固定容量轨道。每次数据重复内部使用同一无限IID流的嵌套前缀。
画总超额风险、运营遗憾，并记录p、范数及p log(e+p)/T。这个比例是多项式包络下的
复杂度趋势代理，不等于完整带常数的有限样本界。不得沿一条曲线同时增加M或改变DGP。
实际下降速度不必等于最坏情形上界指数；不能把有限曲线当成极限证明。

## 6. 性能三组实验

开发训练2000日、验证500日、独立测试3000日；冻结配置和轮数后，从头以2500日重训。
10份独立数据，各随机方法3个训练种子；先在数据重复内平均训练种子，再估计重复间波动。
主tau为0.5/0.6/0.7/0.8/0.9，0.95单列尾部扩展；target为260/280/300/320/340。
每个tau独立训练，target仅影响策略和评价。DAT按验证pinball选择轮数/配置，不跨target训练。
各可训练方法预先分配相同验证搜索预算并登记搜索空间，不按测试表现追加某一模型的搜索。
每方法至多12个有效验证候选，确定性SAA没有需要补足的搜索。
DAT/DeepQR/Flat-ETO用学习率{0.0001,0.0003,0.001}乘batch{32,64,128,256}，
最多240轮、patience30。Set-ETO的两个主分布族计入同一预算，使用3个学习率乘
batch{64,128}乘2个分布族，共12个候选。其他模型的有效网格在入口接入时完整登记，
不得超出预算或借测试挑选。参数相近的池化诊断以总参数差不超过5%为目标。

### P1 基准比较

S1–S4：DAT、SAA、wSAA、Rolling-SAA、Flat-ETO、Set-ETO、LQR、GBQR、DeepQR。
DeepQR是Deep Sets分位回归，保留独立目录；严格容量匹配的池化变体放在DAT消融中。
完全合成数据没有医院实际q_hist，Historical Receipt不伪造、不参加这部分。
主指标P=1-C_method/C_SAA；分母SAA与被比较方法使用同一拟合样本及同一测试日。
同时给成本、Bayes运营遗憾、pinball、覆盖率、平均q、q=0比例和耗时。

Flat-ETO保持离散订单PMF，对新增连续余量估计条件经验CDF，按混合CDF卷积求分位数；
不能给Flat真实J/U或oracle参数，也不能为兼容旧接口而给它另一个取整标签。
Set-ETO主比较使用Normal、HurdleGamma。原NegativeBinomial不能直接对连续D使用离散似然；
若保留该族，需显式实现0.5*NB+Uniform(0,0.5)的连续分箱密度及分位函数，单列敏感性。
所有方法保留同一标签与可见信息。Flat额外使用订单结果监督须在结果表注明。

### P2 DAT结构消融

S2/S3/S4：full、no_self_attention、mean_pool、sum_pool、no_day_query。
最后一项使用可训练常数query；X仍经日级残差和后续FFN进入，避免把结构与信息同时删掉。
前三种结构改动不删除A/X/I的可见字段；必要的mask按原集合处理。
另做mean/sum与full参数量相近的辅助对照，报告真实参数量，不只比较固定宽度。
原“no_inventory”“no_planned_use”“softplus_beta6”不混入这组主结构比较。

### P3 信息价值

固定同一128维DAT及参数总数，每一级从头训练。用输入门控及dummy token避免人数泄漏：

| 等级 | 可见输入 |
| --- | --- |
| L0 | c_1,c_2,I；无订单及人数/订单汇总 |
| L1 | L0 + N/M、两种申请量总和 |
| L2 | L1 + 临床风险均值和二阶矩 |
| L3 | L2 + 逐订单u_i,v_i；隐藏逐订单r_i |
| L4 | L3 + 逐订单r_i，即完整信息 |

L0–L2不向网络暴露实际token数量；L3隐藏临床坐标的同时保留L2已授权临床汇总。
有限样本DAT不保证逐级单调改善；Bayes信息价值才具有信息集合嵌套下的理论单调性。
如要区分信息损失和学习损失，额外计算各等级自己的条件oracle，不能套用完整信息oracle。

## 7. 评价、图及实施门槛

统一 q=max(Q_tau+G-I,0)，成本为tau*max(G-I-q+D,0)+(1-tau)*max(I+q-D-G,0)。
理论图：T1尾部误差—T；T2可达到误差—实际参数量；T3固定/增长容量的超额风险—T；
另画运营遗憾与pinball超额风险的桥梁，检查同一事件控制所有确定性G的含义。
性能图：方法×tau×target成本/P对照；结构消融配对差；信息阶梯及新增信息的成本改善。
统计单位是独立数据重复，同一重复内各方法配对。数据seed、训练seed、oracle积分seed隔离。
训练标签不包含oracle。原始明细、生成数据、权重及结果全部留本机；Git仅保存代码和协议。

正式运行前，依次完成新生成器/固定变换、条件oracle、标量tau调度、连续Flat/Set接口、
理论三组入口、mask/置换/投影/恢复测试，再做六组小规模端到端核验。
在这些门槛通过以前，不把旧v2训练当作本协议的实验，也不声称六组已启动。
